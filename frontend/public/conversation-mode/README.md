# 対話モード用アイコン

このフォルダに画像を配置すると、malchanの対話モード起動ボタンとassistantメッセージのアイコンへ表示されます。

## 対応ファイル名

次の順番で最初に読み込めた画像を使用します。

1. `icon.png`
2. `icon.svg`
3. `icon.webp`
4. `icon.jpg`
5. `icon.jpeg`

画像が存在しない場合、読み込めない場合、または画像形式が不正な場合は、従来の `m` を表示します。ユーザー側の `自` アイコンには画像を適用しません。

## 推奨

- 正方形
- 128 × 128 px以上
- 背景透過のPNGまたはSVG
- アイコン周囲に少し余白を設ける

通常は次の場所へ配置してください。

```text
frontend/public/conversation-mode/icon.png
```
